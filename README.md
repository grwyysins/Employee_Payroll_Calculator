# Employee Payroll Calculator

## Purpose
Register employees and calculate practice payroll figures and payslips.

## Features
- Register and search employees.
- Calculate transport and housing allowances.
- Apply the assignment's practice tax bands.
- Display itemised payslips and payroll summaries.

## Requirements
- Python 3.10 or later
- No third-party packages required

## How to run
1. Open a terminal in this project folder.
2. Run `python main.py`.
3. Follow the on-screen menu.
